## 1.1 背景と課題

既存の Android アラームアプリには次の不満がある。

1. **寝坊防止のために 5 分おきなど複数アラームを登録するが、その ON/OFF を 1 個ずつ切り替えるのが面倒。**
   - 例: 平日用に 6:00 / 6:05 / 6:10 / 6:15 / 6:20 の 5 個を作ると、休みの日に全部 OFF にするのに 5 タップ必要。
2. **同じような設定のアラームを大量に作るのが面倒。**
   - 5 分刻みで 6 個作りたいだけなのに、新規作成フローを 6 回繰り返す必要がある。
3. **「この日は鳴らしたくない」「この日だけ鳴らしたい」を事前にまとめて登録できない。**
   - 有給・出張・帰省などが分かっていても、当日 or 前夜に手作業で OFF にするしかない。

## 1.2 プロダクトのコンセプト

> **「大量のアラームを、束ねて・まとめて作り、まとめて操作できるアラーム」**

個々のアラームの機能で勝負するのではなく、**アラームの「管理コスト」をゼロに近づける**ことを唯一の差別化軸とする。

## 1.3 コア価値（この 3 つが本アプリの存在理由）

| # | コア価値 | 対応する課題 |
|---|---|---|
| CV-1 | **グループ**: 複数アラームを束ね、1 操作で一括 ON/OFF できる | 課題 1 |
| CV-2 | **一括作成**: 「6:00 から 5 分おきに 6 個」を 1 操作で作成できる | 課題 2 |
| CV-3 | **カレンダー先行入力**: 予約日・除外日・祝日を事前に大量登録できる | 課題 3 |

上記以外の機能（音・バイブ・スヌーズ等）は「既存アプリと同等であればよい」領域とし、
差別化のためのリソースを割かない。

## 1.3b 競合状況（調査結果 / 2026-09）

**グループ機能を持つアラームアプリは既に存在する。**

| アプリ | 特徴 |
|---|---|
| グループアラーム（Android） | 早番 / 遅番 / 休日などをグループ化し、グループ単位で ON/OFF できる |
| アラームプラス（iOS / Android） | アラームとタイマーをグループ管理できる |

したがって「グループ化して一括 ON/OFF」だけでは差別化にならない。
**本アプリの優位性は次の 3 点の組み合わせにある。**

| # | 優位点 | 既存アプリとの差 |
|---|---|---|
| 1 | **1 つ解除したら、その日の残りを自動スキップ**（D-008） | 調査した範囲では見当たらない。5 分おきアラーム最大の不満を直接解決する |
| 2 | **間隔と個数を指定した一括作成**（CV-2） | グループを作れても、アラームは 1 件ずつ作るアプリが多い |
| 3 | **予約日・除外日をカレンダーから大量に先行入力**（CV-3） | 「今日だけスキップ」はあっても、数か月先まで一括登録できるものは少ない |

さらに **グループ設定の継承**（D-010）と **実効スケジュールのプレビュー**（FR-4.4）が、
大量のアラームを実際に運用可能にする下支えになる。

> **注意**: 上記は Web 検索による調査であり、網羅的ではない。
> ストアで実際に競合を触ってみると、想定と違う機能があるかもしれない。
> 実装前に主要な既存アプリを一度インストールして確認することを推奨する。

## 1.4 ターゲットユーザー

- 朝が弱く、1 回のアラームでは起きられない人
- 平日 / 休日 / シフト勤務など、日によって起床パターンが変わる人
- 「休みの日にアラームを止め忘れて起こされる」「止め忘れて寝坊する」を繰り返している人

## 1.5 プラットフォーム

- Android 専用（iOS 展開は当面考えない）
- スマートフォン向け。タブレット / Wear OS は対象外（将来検討）

## 1.6 スコープ外（明示的にやらないこと）

- 睡眠トラッキング / いびき録音 / 睡眠スコア
- 天気・ニュース読み上げ
- SNS 連携、ランキング、ソーシャル機能
- アラーム音の大量プリセット / 音源ストア
- クラウド同期（複数端末での共有）※ バックアップ用のエクスポートは行う（→ 05）

## 1.7 用語定義

| 用語 | 定義 |
|---|---|
| アラーム | 1 件の鳴動設定。時刻と繰り返し条件を持つ |
| グループ | 複数のアラームを束ねる単位。一括 ON/OFF と設定の共通化を担う |
| 一括作成 | 起点時刻・間隔・個数を指定して複数アラームを一度に生成する機能 |
| 予約日 | 特定の日付にだけ鳴らす指定（スポット） |
| 除外日 | 繰り返し条件に合致していても鳴らさない日付指定 |
| 実効 ON | 各種条件をすべて評価した結果、その日そのアラームが実際に鳴る状態 |
| 鳴動 | アラームが実際に音・バイブで通知している状態 |
