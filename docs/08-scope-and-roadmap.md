## フェーズ C: 実装 — 土台

- Android プロジェクトの雛形（Compose / Room / Hilt / Version Catalog）
- `willRing()` 判定ロジックとユニットテスト（**UI より先に作る**）
- `AlarmScheduler`（次の 1 件を登録・再計算）
- 鳴動の最小実装（全画面 Activity + Foreground Service + 停止のみ）

> ここが動けば「アラームアプリとして成立する」最低ラインに到達する。
