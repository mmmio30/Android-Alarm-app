---

## フェーズ 0: 土台（実装 1 歩目）

- Android プロジェクトの雛形作成（Compose / Room / Hilt / Version Catalog）
- `willRing()` 判定ロジックとそのユニットテスト（**UI より先に作る**）
- `AlarmScheduler`（次の 1 件を登録・再計算）
- 鳴動の最小実装（全画面 Activity + Foreground Service + 停止のみ）

> ここが動けば「アラームアプリとして成立する」最低ラインに到達する。

## 意図的に「やらない」もの

- クラウド同期 / アカウント機能
- 睡眠トラッキング、いびき録音
- 天気・ニュースの読み上げ
- アラーム音のダウンロードストア
- Wear OS / タブレット最適化
