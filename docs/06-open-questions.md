## A. 実装着手前に決めたいもの

### Q13. minSdk はいくつにするか？
| | 選択肢 |
|---|---|
| A | 26（Android 8.0）。ほぼ全端末をカバー（推奨） |
| B | 29 / 31 など、より新しく。実装は楽になるが対象端末が減る |

Play 公開前提なので、極端に古い端末を切っても実害は小さい。
迷う場合は A（26）で進める。

### Q14. 開発・動作確認に使える実機はあるか？（機種名 / Android バージョン）
エミュレータだけだと OEM 独自の省電力（Xiaomi / OPPO / Huawei 等）の検証ができず、
「一部の端末でだけ鳴らない」という最も厄介な不具合を見逃す。
**手元の端末の機種と OS バージョンを教えてほしい。**

### Q17. 鳴動中のフォアグラウンドサービスの型をどちらにするか？
| | 選択肢 |
|---|---|
| A | `mediaPlayback`（実際に音を鳴らすので自然。ただし審査で用途を問われうる） |
| B | `specialUse`（用途説明を添えて申告する） |

技術的にはどちらでも動く。**Play 審査での通りやすさで決めたい**ので、
実装直前に Play Console の最新の申告フォームを確認して判断する。

### Q18. アプリ名は何にするか？
ストア掲載とパッケージ名（`com.example.xxx` の部分）に必要。
仮でもよいので方向性（日本語名 / 英語名 / 造語）を決めておきたい。

### Q19. Google Play Console のアカウントは既にあるか？
無い場合、登録と本人確認に日数がかかる場合があり、
さらに個人アカウントには公開前のテスト要件が課される可能性がある（→ `09-play-release.md` 9.1）。
**アプリ完成後に着手すると公開がその分遅れる**ため、早めに状況を把握しておきたい。

## B. 仕様の細部（設計フェーズで決めればよい）

### Q6. 「除外日」と「予約日」が同じ日に重なったらどちらを優先するか？
| | 選択肢 |
|---|---|
| A | 除外日が勝つ = 鳴らない（推奨。「有給なので全部止めたい」が直感的） |
| B | 予約日が勝つ = 鳴る（「この日だけは絶対起きたい」を優先） |

### Q7. 祝日データの持ち方は？
| | 選択肢 |
|---|---|
| A | アプリに内蔵（オフライン完結・ネット権限不要・推奨）。法改正時はアプリ更新で対応 |
| B | ネットから年 1 回取得。常に最新だがネット権限とデータセーフティ申告が増える |
| C | A を基本とし、ユーザーが手で祝日を追加・削除できるようにする |

A を選ぶ場合、「祝日データが何年先まで入っているか」をアプリ内に表示し、
期限が近づいたら更新を促す仕組みが要る。

### Q8. 高度な繰り返し（隔週 / N 日おき / シフト勤務）は必要か？
| | 選択肢 |
|---|---|
| A | 不要。除外日の一括登録で代替する（推奨） |
| B | 必要（どういう勤務パターンかを教えてほしい） |

### Q10. イヤホン接続時に「常にスピーカーから鳴らす」オプションは必要か？
イヤホンをしたまま寝る習慣があるかどうかで要否が変わる。

### Q20. 深夜アラーム（例: 深夜 2:00）の「日付」の扱いは直感に合うか？
現案では 2:00 のアラームは「その日の 2:00」として扱う。
つまり「金曜の夜更かし用」に設定したいときは**土曜にチェックを入れる**必要がある。
これを UI でどう補足するか（あるいは「前日の夜」として扱うモードを持つか）。

## C. 後回しでよいもの（フェーズ 2 以降）

### Q5. 解除ミッション（計算問題 / シェイク / タイピング）は入れるか？
D-008（1 つ解除で残りスキップ）と組み合わせると
「ミッションを解かないと残り全部が鳴り続ける」という強力な仕組みになる。
現案ではフェーズ 3。前倒ししたい場合は要相談。

### Q9. 一括作成時の「エスカレーション」（後半ほど音量大 / 音を変える）は必要か？

### Q11. ウィジェット / クイック設定タイルはどの段階で入れるか？
グループ一括 ON/OFF との相性が非常に良い。フェーズ 3 を前倒しする価値はある。

### Q12. Direct Boot 対応（再起動後、ロック解除前でもアラームを鳴らす）を入れるか？
| | 選択肢 |
|---|---|
| A | MVP に入れる |
| B | MVP 外。まずは `BOOT_COMPLETED` のみ（推奨） |
